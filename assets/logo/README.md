# Logo Losse

Logo fourni par le propriétaire du dépôt : **deux requins-marteaux en formation yin-yang**.
Fichier source `Requin_yin-yang_noir_et_blanc__1_-removebg-preview.png`, fond déjà détouré
(vrai canal alpha). Les fichiers ci-dessous sont **recadrés et redimensionnés uniquement** :
l'œuvre n'est jamais recolorée.

## ⚠️ Effet de logo volontaire — ne pas « corriger »

Le logo est noir et blanc, et **c'est délibéré** :

- sur un **fond clair**, seul le **requin noir** se détache ;
- sur un **fond sombre**, seul le **requin blanc** reste visible.

Le second requin n'est pas un oubli : il est invisible selon le fond. Ce procédé protège
l'identité du logo (difficile à reproduire à l'identique sans connaître le fichier source)
et donne l'illusion d'un seul requin.

**Ne jamais** poser de plaque claire, de halo lumineux ou une variante recolorée derrière
le logo : cela rendrait les deux requins visibles et détruirait l'effet.

| `apple-touch-icon.png` | 180 px | clair | écran d'accueil iOS/macOS |

Les favicons sont posés sur un fond clair : les onglets de navigateur peuvent être sombres
comme clairs, une icône transparente y serait illisible.

Les `.webp` sont servis en priorité par le hub quand le navigateur les accepte (poids divisé
par ~3), avec repli automatique en PNG.
