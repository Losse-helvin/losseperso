⚠️
Clair a besoin du petit serveur fourni. Vous avez ouvert cette page directement en file://. GestiProj fonctionne tel quel ; pour Clair, lancez python3 launch.py (ou launch.bat sous Windows) puis ouvrez http://localhost:8000.

Comment démarrer

1 Lanceur unique (recommandé)

À la racine du dépôt : python3 launch.py. Une seule adresse sert les deux applications, relais Google compris.

2 GestiProj seul

Double-cliquez GestiProj/index.html. Aucun serveur, aucune dépendance : tout fonctionne en local.

3 Clair seul

Dans son dossier : python3 serve.py. Obligatoire pour les modules ES6 et le mode lien partagé.

Démarrer depuis la racine du dépôt

Python 3.9+ suffit — aucune dépendance à installer.

$python3 launch.py
$python3 launch.py --port 8001
>launch.bat

Bon à savoir

  • ✓Une seule origine. Le serveur racine expose /api/public-sheet pour le mode lien partagé.
  • ✓Données cloisonnées. GestiProj stocke dans le navigateur, Clair ne conserve rien.
  • ✓Rien n'est écrasé. Chaque application garde ses fichiers, son serveur et ses tests.
